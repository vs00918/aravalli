## 🔬 Ingestion & Merging Guidelines
1. **Continuation**: If incoming knowledge refines an existing node, merge it seamlessly to expand explanatory depth.
2. **New Concept**: If it introduces a genuinely new cognitive mechanism or framework, add it as the next chronological chapter.
3. **Deduplication**: Skip redundant information, preserving only maximum signal density.
4. **Auditing**: Audit claims against neuroscience and first principles before adding.
