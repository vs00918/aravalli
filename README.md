# Mind of Aravalli

> **A living personal encyclopedia that turns scattered information into structured, connected, durable understanding.**

---

## What is Mind of Aravalli?

**Mind of Aravalli** is a digital encyclopedia and intellectual laboratory built from first principles. It helps curious thinkers consume complex information from many sources and progressively transform that information into a coherent, interconnected body of knowledge.

Unlike generic note-taking apps or AI chat tools, Mind of Aravalli prioritizes:
1. **Understanding over summarization**
2. **Concepts over documents**
3. **Connections over categories**
4. **First principles over surface facts**
5. **Durable knowledge over fleeting feeds**

---

## Core Capabilities

* 📖 **Master Library**: 5 foundational master volumes spanning Physics, Energy, Biology, Complex Systems, and Society.
* 🎓 **6-Layer Concept Reading Experience**: Progressive explanation architecture from plain-language definitions to KaTeX mathematics, cross-domain connections, and boundary limitations.
* 🌿 **The Knowledge Lattice**: First-class relational connections distinguishing mathematical isomorphisms from physical equivalence.
* 📡 **Curiosity Radar**: Unresolved inquiry questions serving as navigational doorways into the concept graph.
* 📥 **Living Ingestion Engine & Inbox**: Safe staging area and research review desk ensuring AI extractions never automatically pollute the master encyclopedia without human audit.
* 🔍 **Global Search (`Ctrl+K`)**: Instant search across Concepts, Chapters, Connections, Questions, and Sources.
* 🔖 **Reading Progress & Bookmarks**: Local reading history and saved bookmarks.

## Getting Started

### Prerequisites
* Node.js 18+
* npm

### Installation & Run

```bash
# Install dependencies
npm install

# Seed knowledge database
npm run db:seed

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
